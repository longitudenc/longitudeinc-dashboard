Pay week

Pulls the Payroll Consolidated report straight from SD3 for the Saturday–Friday week — the same report you used to download by hand — then applies cross-salon overtime and 6-day pay before writing the ADP file.

Hand-keyed earnings

Lines SD3 doesn't know about — referral and sign-on bonuses, guarantees, manager cell, tuition, retro pay. They're saved against the pay week, so rebuilding the upload keeps them. Payroll ID is the File # ADP uses; the code is the ADP earnings code.
